# Legal-Ease-chatbot


Built an intelligent legal assistant using Retrieval Augmented Generation (RAG) architecture to answer natural language legal questions from large legal document collections.

Key Features:

Processed 1,200+ legal documents
Text cleaning, chunking, and embedding pipeline
Semantic vector search for relevant context retrieval
LLM-based answer generation
Evaluated using 100+ benchmark queries

Tech Stack: Python, LangChain, FAISS/ChromaDB, OpenAI/LLM APIs, NLP
